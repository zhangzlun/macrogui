# 講義 05：投資組合

對應第五課。這一課的數學說明了「分散」為什麼有用。

## 1. 組合的報酬

```
組合報酬 = 權重A × 報酬A + 權重B × 報酬B + …
```

**例題**：60% 股票、40% 債券。今天股票 +2%，債券 −1%。

```
0.6 × 2% + 0.4 × (−1%) = 1.2% − 0.4% = 0.8%
```

## 2. 組合的波動度：分散的核心

兩個資產時：

```
組合變異數 = wA² × σA² + wB² × σB² + 2 × wA × wB × ρ × σA × σB
組合波動度 = √組合變異數

w = 權重，σ = 波動度，ρ = 兩者的相關係數
```

**白話**：組合的波動不是兩個波動的平均。相關係數 ρ 越低，組合越穩。

**例題**：兩個資產波動度都是 20%，各放 50%。

```
共同部分：wA² × σA² + wB² × σB²
         = 0.25 × 0.04 + 0.25 × 0.04 = 0.02

相關項：  2 × 0.5 × 0.5 × ρ × 0.2 × 0.2 = 0.02 × ρ
```

| 相關係數 ρ | 組合變異數 | 組合波動度 |
| --- | --- | --- |
| 1（完全同步） | 0.02 + 0.02 = 0.04 | √0.04 = 20% |
| 0.5 | 0.02 + 0.01 = 0.03 | √0.03 = 17.3% |
| 0（無關） | 0.02 | √0.02 = 14.1% |
| −1（完全相反） | 0.02 − 0.02 = 0 | 0% |

報酬不變（兩個資產報酬一樣時，組合報酬也一樣），波動卻下降了。
這就是為什麼分散被稱為「唯一的免費午餐」。
現實中很難找到 ρ 是負的資產，但只要不是 1，就有好處。

## 3. 反波動度加權

```
1. 每個資產算 1 ÷ 波動度
2. 全部加起來
3. 權重 = 自己的 (1 ÷ 波動度) ÷ 加總
```

**白話**：越穩的資產分到越多錢，讓每個資產對組合的晃動貢獻差不多。

**例題**：股票波動度 20%，債券 10%。

```
股票：1 ÷ 0.2 = 5
債券：1 ÷ 0.1 = 10
加總：15

股票權重 = 5 ÷ 15 = 1/3 ≈ 33%
債券權重 = 10 ÷ 15 = 2/3 ≈ 67%
```

驗算：`33% × 20% ≈ 6.7%`，`67% × 10% ≈ 6.7%`，兩邊的波動貢獻一樣。

## 4. 權重漂移與再平衡

```
漂移後的權重 = 該資產目前市值 ÷ 組合總市值
再平衡換手率 = Σ |目標權重 − 漂移後權重|
```

**白話**：一開始設 50/50，之後漲多的那檔佔比會自動變大。
再平衡就是賣掉漲多的、買進漲少的，拉回目標。

**例題**：100 萬，A、B 各 50 萬。後來 A 翻倍，B 不動。

```
A 市值 100 萬，B 市值 50 萬，總共 150 萬
漂移後權重：A = 100 ÷ 150 = 2/3，B = 50 ÷ 150 = 1/3

拉回 50/50：各要 75 萬
A 賣 25 萬，B 買 25 萬
換手率 = |1/2 − 2/3| + |1/2 − 1/3| = 1/6 + 1/6 = 1/3
```

單邊成本 10 bp 時，這次再平衡的成本是 `1/3 × 0.1% ≈ 0.033%`。
再平衡越頻繁，每次漂移越少，但次數越多。第五課比較了每週、每月、每季、每年。

## 練習題

1. 70% 股票、30% 黃金。今天股票 −3%，黃金 +2%。組合報酬是多少？
2. 兩個資產波動度都是 30%，各放 50%，相關係數 0。組合波動度是多少？
3. 承上題，如果相關係數是 0.6 呢？
4. 三個資產波動度 10%、20%、40%。反波動度權重各是多少？
5. 100 萬，60% 股票、40% 債券。一年後股票漲 50%、債券不動。漂移後的權重是多少？拉回 60/40 的換手率是多少？

## 解答

1. `0.7 × (−3%) + 0.3 × 2% = −2.1% + 0.6% = −1.5%`
2. `0.25 × 0.09 + 0.25 × 0.09 = 0.045`，`√0.045 ≈ 21.2%`
3. 再加 `2 × 0.5 × 0.5 × 0.6 × 0.3 × 0.3 = 0.027`，變異數 `0.072`，`√0.072 ≈ 26.8%`
4. `1/0.1 = 10`、`1/0.2 = 5`、`1/0.4 = 2.5`，加總 17.5。權重 `10/17.5 ≈ 57.1%`、`5/17.5 ≈ 28.6%`、`2.5/17.5 ≈ 14.3%`
5. 股票 90 萬、債券 40 萬，總共 130 萬。權重 `90/130 ≈ 69.2%`、`40/130 ≈ 30.8%`。換手率 `|60% − 69.2%| + |40% − 30.8%| ≈ 18.5%`
