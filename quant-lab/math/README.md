# 數學講義

課程程式只印出「算好的答案」。這份講義教你那些答案是怎麼算出來的。

每一份講義都有四個部分：

1. **公式**：用一般文字寫，不用看懂數學符號也能讀
2. **白話**：這個數字在說什麼、為什麼要這樣算
3. **手算例題**：用很小的數字一步一步算給你看
4. **練習題**：最後附解答，先自己算再對答案

需要的數學只有：加減乘除、百分比、次方、開根號。
手機的計算機橫過來就有次方和開根號。`ln` 和 `e^x` 也在科學計算機裡。

想在手機或瀏覽器上讀，打開 `math/handouts.html`（五份合在一起，解答預設收起來）。
改了講義之後，用這行重新產生：

```
uv run --with markdown python math/build_html.py
```

想確認「手算的跟程式算的一樣」，執行：

```
uv run python math/check_examples.py
```

它會用專案裡的函式重算每一題例題，並印出對照。
