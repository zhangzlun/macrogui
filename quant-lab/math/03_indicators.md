# 講義 03：指標與策略

對應第三課。

## 1. 動能

```
N 日動能 = 今天價格 ÷ N 天前的價格 − 1
```

**白話**：過去 N 天總共漲跌多少。動能策略賭「漲的會繼續漲」。

**例題**：今天 120 元，126 個交易日前（約半年）是 100 元。

```
120 ÷ 100 − 1 = 20%  → 大於 0，持有
```

## 2. RSI（相對強弱指標）

```
1. 算每天的漲跌：今天價格 − 昨天價格
2. 漲的日子記「漲幅」，跌的日子記「跌幅」（取正數），另一個記 0
3. 平均漲幅、平均跌幅（最近 N 天）
4. RS  = 平均漲幅 ÷ 平均跌幅
5. RSI = 100 − 100 ÷ (1 + RS)
```

**白話**：最近 N 天裡，漲的力道佔了多少。全部都在漲就是 100，全部都在跌就是 0。
一般 70 以上叫「超買」，30 以下叫「超賣」。

**例題**：收盤價 10、11、12、11、13、14，用 5 天、簡單平均。

```
每天漲跌：    +1   +1   −1   +2   +1
漲幅：         1    1    0    2    1   → 平均 5 ÷ 5 = 1.0
跌幅：         0    0    1    0    0   → 平均 1 ÷ 5 = 0.2
RS  = 1.0 ÷ 0.2 = 5
RSI = 100 − 100 ÷ (1 + 5) = 100 − 16.7 = 83.3
```

**程式裡的版本稍有不同**：程式用的是「Wilder 平滑法」，平均的方式類似 EMA，
α = 1 ÷ N，越近的日子權重越大。所以程式算出的 RSI 跟手算的簡單平均版不會完全一樣，
但概念相同。

## 3. RSI 均值回歸策略

```
RSI < 30 → 買進，之後一直持有
RSI > 70 → 賣出，之後一直空手
中間     → 維持原本的狀態
```

**白話**：跌太多就買，賭它會彈回來；漲太多就賣。跟動能策略的想法相反。

## 4. 波動度目標

```
部位 = 目標波動度 ÷ 最近的實際波動度
部位上限 = 1（不借錢）
```

**白話**：市場越晃，買越少，讓整體的晃動維持在差不多的水準。

**例題**：目標 15%。

| 最近波動度 | 計算 | 部位 |
| --- | --- | --- |
| 30% | 15 ÷ 30 = 0.5 | 0.5 |
| 15% | 15 ÷ 15 = 1 | 1 |
| 10% | 15 ÷ 10 = 1.5 | 超過上限，取 1 |

## 5. 索提諾值

```
下檔偏差 = √( 每天 min(報酬, 0) 的平方，取平均 )
索提諾值 = 日平均報酬 ÷ 下檔偏差 × √252
```

**白話**：夏普值把「大漲」也算成風險，但投資人只怕跌。索提諾值只把下跌的部分當風險。

**例題**：五天報酬 +2%、−1%、+3%、0%、−1%。

```
平均：(2 − 1 + 3 + 0 − 1) ÷ 5 = 0.6%

標準差（講義 01 的方法）：
  離差 1.4  −1.6  2.4  −0.6  −1.6
  平方 1.96  2.56  5.76  0.36  2.56   加總 13.2
  13.2 ÷ 4 = 3.3，√3.3 = 1.817%

下檔偏差：
  只留負的：0  −1  0  0  −1
  平方：    0   1  0  0   1   加總 2
  2 ÷ 5 = 0.4，√0.4 = 0.632%

日夏普值   = 0.6 ÷ 1.817 = 0.33
日索提諾值 = 0.6 ÷ 0.632 = 0.95
```

這組資料大漲多、小跌少，所以索提諾值比夏普值高很多。
（下檔偏差除以「個數」，不是「個數 − 1」，這是常見的寫法。）

## 6. 卡瑪值

```
卡瑪值 = 年化報酬 ÷ |最大回撤|
```

**例題**：年化 8%，最大回撤 −20%。`8 ÷ 20 = 0.4`

**白話**：每承受 1% 的最大回撤，每年換到多少報酬。

## 7. 相關係數

```
1. 兩組數字各自算平均，各自算離差
2. 對應的離差相乘，全部加起來                 ← 分子
3. 兩組各自的「離差平方和」相乘，再開根號      ← 分母
4. 相關係數 = 分子 ÷ 分母
```

**白話**：兩個東西是不是一起漲跌，介於 −1 到 1。
1 是完全同步，0 是沒關係，−1 是完全相反。

**例題**：A 四天報酬 1、2、3、4，B 四天報酬 1、3、2、4。

```
平均：A = 2.5，B = 2.5
A 離差：−1.5  −0.5   0.5  1.5
B 離差：−1.5   0.5  −0.5  1.5
相乘：   2.25 −0.25 −0.25 2.25   加總 = 4

A 離差平方和：2.25 + 0.25 + 0.25 + 2.25 = 5
B 離差平方和：5
分母：√(5 × 5) = 5

相關係數 = 4 ÷ 5 = 0.8
```

## 8. 日勝率與持倉時間

```
日勝率   = 賺錢的天數 ÷ 有損益的天數（報酬剛好 0 的不算）
持倉時間 = 有持倉的天數 ÷ 總天數
```

**注意**：勝率高不代表賺錢。勝率 90% 但每次小賺、偶爾大虧，一樣會虧。

## 練習題

1. 今天 85 元，半年前 100 元。動能是多少？動能策略會不會持有？
2. 五天收盤價 20、21、20、22、23。用簡單平均算 4 天的 RSI（只看最後 4 天的漲跌）。
3. 目標波動度 12%，最近波動度 24%。部位是多少？如果最近波動度 8% 呢？
4. 年化報酬 6%，最大回撤 −30%。卡瑪值是多少？
5. 三天報酬 +1%、−2%、+4%。算下檔偏差（除以個數）。
6. A 三天報酬 1、2、3，B 三天報酬 3、2、1。相關係數是多少？先猜再算。

## 解答

1. `85 ÷ 100 − 1 = −15%`，小於 0，空手
2. 漲跌 +1、−1、+2、+1。平均漲幅 `(1 + 0 + 2 + 1) ÷ 4 = 1`，平均跌幅 `(0 + 1 + 0 + 0) ÷ 4 = 0.25`。`RS = 4`，`RSI = 100 − 100 ÷ 5 = 80`
3. `12 ÷ 24 = 0.5`；`12 ÷ 8 = 1.5`，超過上限取 1
4. `6 ÷ 30 = 0.2`
5. 只留負的 0、−2、0，平方加總 4，`4 ÷ 3 = 1.33`，`√1.33 ≈ 1.15%`
6. 完全相反，−1。離差 A：−1、0、1；B：1、0、−1。相乘加總 −2；平方和各 2，分母 `√4 = 2`；`−2 ÷ 2 = −1`
