# 講義 01：報酬與風險

對應第一課。

## 1. 簡單報酬率

```
報酬率 = 今天價格 ÷ 昨天價格 − 1
```

**白話**：漲跌了百分之幾。

**例題**：昨天 100 元，今天 110 元。

```
110 ÷ 100 − 1 = 1.10 − 1 = 0.10 = 10%
```

## 2. 多天的報酬要「連乘」，不能相加

```
總報酬 = (1 + 第一天報酬) × (1 + 第二天報酬) × … − 1
```

**白話**：第二天的漲跌，是在第一天「已經變動過的金額」上再漲跌。

**例題**：先漲 10%，再跌 10%，是不是回到原點？

```
(1 + 0.10) × (1 − 0.10) − 1
= 1.10 × 0.90 − 1
= 0.99 − 1
= −1%
```

**沒有回到原點，還虧了 1%。** 100 元漲 10% 變 110 元，110 元跌 10% 是跌掉 11 元，剩 99 元。

這也是為什麼「跌下去比漲回來容易」，第 6 節的回撤會再講。

## 3. 對數報酬率

```
對數報酬 = ln(今天價格 ÷ 昨天價格)
換回簡單報酬 = e^(對數報酬) − 1
```

**白話**：`ln` 是「e 要幾次方才會等於這個數」，e ≈ 2.718。
你不用懂它的原理，只要知道它的一個好用性質：**對數報酬可以直接相加**。

**例題**：一樣先漲 10%、再跌 10%。

```
第一天：ln(1.10) = 0.09531
第二天：ln(0.90) = −0.10536
相加：  0.09531 + (−0.10536) = −0.01005
換回來：e^(−0.01005) − 1 = −0.0100 = −1%
```

跟第 2 節連乘的答案一樣。漲跌幅小的時候，對數報酬和簡單報酬幾乎相同。
第一課印出的「最近五天」那張表就在對照這兩種。

## 4. 年化報酬（CAGR）

```
年化報酬 = (期末金額 ÷ 期初金額) ^ (1 ÷ 年數) − 1
年數 = 交易日天數 ÷ 252
```

**白話**：如果每年都賺一樣多的百分比，要每年賺多少，才會從期初變成期末？
一年大約有 252 個交易日（扣掉週末和假日），所以用天數除以 252 換成年。

**例題**：100 元，10 年後變 200 元。

```
(200 ÷ 100) ^ (1 ÷ 10) − 1
= 2 ^ 0.1 − 1
= 1.0718 − 1
= 7.18%
```

**驗算**：1.0718 乘自己 10 次 ≈ 2，沒錯。
注意不是 100% ÷ 10 年 = 10%，因為報酬會「利滾利」。

## 5. 平均數、標準差、年化波動度

### 平均數

```
平均數 = 全部加起來 ÷ 個數
```

### 標準差

```
1. 每個數減掉平均數（叫做「離差」）
2. 每個離差平方
3. 全部加起來，除以 (個數 − 1)  ← 這叫「變異數」
4. 開根號  ← 這就是標準差
```

**白話**：每天的報酬平均離「平均值」多遠。越大代表上下晃得越厲害。
第 3 步除以「個數 − 1」而不是「個數」，是統計上用樣本估計時的修正，記住就好。

**例題**：五天的日報酬是 +1%、−2%、+3%、0%、−2%。

```
平均數：(1 − 2 + 3 + 0 − 2) ÷ 5 = 0 ÷ 5 = 0%

離差：    1   −2    3    0   −2      （每個減 0）
平方：    1    4    9    0    4
加總：    1 + 4 + 9 + 0 + 4 = 18
除以 4：  18 ÷ 4 = 4.5
開根號：  √4.5 = 2.12

日標準差 = 2.12%
```

### 年化波動度

```
年化波動度 = 日標準差 × √252
√252 ≈ 15.87
```

**白話**：把「每天晃多少」換算成「一年晃多少」。

**為什麼是乘 √252 而不是乘 252？**
假設每天的漲跌互不相關，那麼「變異數」（標準差的平方）可以一天一天加起來：
一年的變異數 = 252 × 日變異數。開根號回來，就是 √252 × 日標準差。

**例題**：上面那五天，日標準差 2.12%。

```
2.12% × 15.87 = 33.7%
```

一般大盤的年化波動度大約 15%～20%，個股常常 30% 以上。

## 6. 夏普值

```
夏普值 = 年化（平均報酬 − 無風險利率） ÷ 年化波動度
程式裡的算法 = 日平均超額報酬 ÷ 日標準差 × √252
```

**白話**：每承受 1 單位的波動，換到多少報酬。可以拿來比較「報酬高但很晃」和「報酬低但很穩」的兩個東西。
大致的感覺：0.5 普通、1 不錯、2 以上要先懷疑回測有沒有錯。

**例題**：某資產日平均報酬 0.04%，日標準差 1%，無風險利率當作 0。

```
0.04% ÷ 1% × 15.87 = 0.04 × 15.87 = 0.63
```

**例題 2（有無風險利率）**：某策略年化報酬 10%，年化波動度 16%，無風險利率（例如定存）2%。

```
(10% − 2%) ÷ 16% = 8 ÷ 16 = 0.5
```

先把報酬扣掉「什麼都不做也拿得到」的無風險利率，剩下的才是冒風險換來的。

**為什麼分子分母都乘時間，結果只乘 √252？**
平均報酬年化要乘 252，標準差年化要乘 √252，相除：252 ÷ √252 = √252。

## 7. 常態分布與「3 個標準差」

```
z 分數 = (某天報酬 − 平均報酬) ÷ 標準差
```

**白話**：這天的漲跌是「幾個標準差」那麼極端。

如果報酬是常態分布（鐘形曲線）：

| 範圍 | 落在範圍內的比例 | 落在範圍外的比例 |
| --- | --- | --- |
| ±1 個標準差 | 68% | 32% |
| ±2 個標準差 | 95% | 5% |
| ±3 個標準差 | 99.73% | 0.27% |

**例題**：第一課的資料有 5682 天。如果是常態分布，超過 ±3 個標準差的天數應該是：

```
5682 × 0.27% = 5682 × 0.0027 ≈ 15 天
```

實際上常常是這個數字的好幾倍。這就是「肥尾」：極端行情比常態分布說的更常發生。
用常態分布估計風險，會低估大跌的機率。

### 偏態和峰態

| 指標 | 怎麼算（概念） | 怎麼讀 |
| --- | --- | --- |
| 偏態 | 每天 z 分數的「三次方」取平均 | 負數：大跌比大漲更極端 |
| 峰態 | 每天 z 分數的「四次方」取平均，再減 3 | 大於 0：極端值比常態分布多 |

三次方保留正負號，所以看得出往哪邊偏；四次方把極端值放得很大，所以對肥尾很敏感。
pandas 實際用的公式還多了樣本修正，數字會差一點，不用手算。

## 8. 回撤與最大回撤

```
回撤 = 目前淨值 ÷ 到目前為止的最高淨值 − 1
最大回撤 = 所有回撤裡最小（最負）的那個
```

**白話**：你現在離「帳面最高點」虧了多少。最大回撤是整段期間最痛的那一刻。

**例題**：淨值依序是 100、120、90、130、104。

| 天 | 淨值 | 到目前最高 | 回撤 |
| --- | --- | --- | --- |
| 1 | 100 | 100 | 100 ÷ 100 − 1 = 0% |
| 2 | 120 | 120 | 0% |
| 3 | 90 | 120 | 90 ÷ 120 − 1 = −25% |
| 4 | 130 | 130 | 0% |
| 5 | 104 | 130 | 104 ÷ 130 − 1 = −20% |

最大回撤 = −25%。

**容易算錯的地方**：「最高」是指**到那天為止的整段歷史最高**，不是前一天。
例如淨值 100、120、90、110、80：第 5 天的 80 要跟 120 比，`80 ÷ 120 − 1 = −33.3%`，
不是跟前一天的 110 比。中間反彈到 110 沒有創新高，所以高點還是 120。

### 虧損之後要賺多少才回本

```
回本需要的漲幅 = 1 ÷ (1 − 虧損比例) − 1
```

| 虧損 | 回本要漲 |
| --- | --- |
| −10% | +11.1% |
| −20% | +25% |
| −30% | +42.9% |
| −50% | +100% |
| −75% | +300% |

**例題**：虧 50%。`1 ÷ (1 − 0.5) − 1 = 1 ÷ 0.5 − 1 = 2 − 1 = 100%`。
100 元剩 50 元，要翻倍才回到 100 元。這就是為什麼量化特別重視控制回撤。

## 9. 滾動計算

```
滾動 N 日的某指標 = 只用「最近 N 天」的資料算那個指標，每天往後挪一天重算
```

**白話**：第一課的「一個月滾動波動度」，就是每天都用最近 21 個交易日算一次年化波動度。
這樣可以看到波動度隨時間怎麼變化，而不是整段期間只有一個數字。

## 練習題

1. 一檔股票從 50 元漲到 60 元，報酬率是多少？
2. 連續三天報酬是 +5%、−3%、+2%，三天的總報酬是多少？
3. 一筆投資 3 年從 100 萬變成 150 萬，年化報酬是多少？
4. 四天的日報酬是 +2%、0%、−2%、+4%。算出日標準差，再算年化波動度。
5. 某策略日平均報酬 0.05%，日標準差 1.2%。夏普值大約是多少？
6. 淨值依序是 1.0、1.3、1.1、0.9、1.2、1.4。最大回撤是多少？發生在哪一天？
7. 一個策略最大回撤 −40%。從谷底要漲多少才能回到前高？
8. 一段資料有 2520 天。如果報酬是常態分布，超過 ±2 個標準差的天數大約幾天？

## 解答

1. `60 ÷ 50 − 1 = 0.2 = 20%`
2. `1.05 × 0.97 × 1.02 − 1 = 1.03887 − 1 ≈ 3.89%`（不是 5 − 3 + 2 = 4%）
3. `1.5 ^ (1 ÷ 3) − 1 = 1.1447 − 1 ≈ 14.47%`
4. 平均 `(2 + 0 − 2 + 4) ÷ 4 = 1%`。離差 1、−1、−3、3，平方 1、1、9、9，加總 20，`20 ÷ 3 = 6.67`，`√6.67 ≈ 2.58%`。年化 `2.58% × 15.87 ≈ 41%`
5. `0.05 ÷ 1.2 × 15.87 ≈ 0.66`
6. 最高點 1.3 之後跌到 0.9：`0.9 ÷ 1.3 − 1 ≈ −30.8%`，發生在第 4 天
7. `1 ÷ (1 − 0.4) − 1 = 1 ÷ 0.6 − 1 ≈ 66.7%`
8. `2520 × 5% = 126` 天
